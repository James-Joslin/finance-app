# Support

Finova is a community-maintained, self-hosted project. Support is provided on a best-effort basis without a guaranteed response time.

## Getting help

1. Read the [README](README.md), especially the production, backup/restore, and troubleshooting sections.
2. Search existing [issues](https://github.com/James-Joslin/finance-app/issues).
3. If the problem has not already been reported, use the appropriate issue template.

When requesting help, include:

- The Finova image tag or commit SHA.
- Host operating system, CPU architecture, Docker version, and Compose version.
- Relevant service status and sanitised logs.
- The command that failed and the result you expected.

Do not include real financial data, environment-file contents, passwords, tokens, connection strings, database dumps, backup archives, or private images. Replace identifying values with clearly marked examples.

## Security issues

Do not use a public support issue for a suspected vulnerability. Follow [SECURITY.md](SECURITY.md).

## Data recovery

Make a verified backup before attempting database repair, restoration, schema changes, or destructive troubleshooting. Project maintainers cannot recover data from your host and cannot guarantee recovery from an untested backup.
